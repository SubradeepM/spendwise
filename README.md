# SpendWise 💰
### AI-Powered Zero-Cost Budgeting Tool

🔗 **Live Demo → https://SubradeepM.github.io/spendwise**


## What it does
SpendWise uses AI vision models to scan receipt photos and videos,
automatically extracting merchant names, amounts, dates, and categories —
eliminating all manual data entry for personal finance tracking.

## Features
- 📸 Receipt scanner — supports JPG, PNG, PDF, MP4, HEIC
- 🤖 AI auto-categorization with 97% confidence scoring
- 📊 Spending dashboard with live category breakdown
- 📅 Budget tracker across 8 categories (Groceries, Food, Utilities, etc.)
- 💬 AI Advisor chatbot for personalized spending insights
- 📈 Weekly trend analysis and overspend alerts

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Claude AI API (Vision + Chat)
- Zero dependencies — runs in any browser
